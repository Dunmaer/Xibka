# Проклинатель Online · The Curser Online

Страница-игра, где проклинают. Посетитель пишет имя, причину и наказание. Бумажка падает на алтарь,
алтарь затягивает её в вихрь, над ним раскрывается многослойный магический круг, и в конце из
центра рождается сертификат проклятия с восковой печатью. Всё работает в браузере, на сервер ничего
не отправляется. Проклятия сохраняются в архиве на компьютере пользователя.

Стек: **Vite + React + TypeScript + Three.js + GSAP**, без бэкенда.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # production-сборка в dist/
npm run preview      # посмотреть собранную версию
```

Нужен Node.js 20+.

## Деплой

Сайт полностью статический: надо собрать и выложить папку `dist/`.

| Хостинг | Настройки |
|---|---|
| **Vercel** | Import Git Repository → Framework: *Vite* → Build: `npm run build` → Output: `dist` |
| **Cloudflare Pages** | Build command: `npm run build` → Build output: `dist` → переменная `NODE_VERSION=20` |
| **Netlify** | Build command: `npm run build` → Publish directory: `dist` |

В `vite.config.ts` стоит `base: './'`, поэтому сборка работает и из подпапки (например GitHub Pages).
Видео весят ~5 МБ (MP4) и ~2.5 МБ (WebM) каждое, ограничения хостингов на размер файла не нарушаются.

## Как устроен ритуал

Всё синхронизировано с **номером кадра видео `pribliji.mp4`** (24 fps, 271 кадр).
Номер кадра берётся из `requestVideoFrameCallback`, поэтому эффекты попадают точно в кадр.
Все тайминги собраны в одном файле: `src/features/ritual/timeline.ts`.

| Кадры `pribliji` | Что происходит |
|---|---|
| до старта | Крутится `stable.mp4`. После «Начать ритуал» бумажка с текстом появляется перед зрителем и падает листом на центр алтаря |
| 0–175 | Включается `pribliji.mp4` (стык подобран без шва). Бумажка лежит на камне: греется, по краям темнеет, сквозь неё проступают «адские» буквы в цвете проклятия |
| **175** | Открывается **туннель**: части круга, кольца надписей, сигилы и спутники летят из глубины вихря |
| 175–245 | Камера ныряет в вихрь (масштаб замерен по видео). Части круга по одной прилетают на свои места и **собираются в круг** (у каждого своя вспышка фиксации). Другие элементы пролетают мимо камеры и уходят за кадр. Бумажка проваливается в туннель и сгорает |
| **245** | Круг собран: удар, искры, огонь, появляются летящие надписи (цепочки букв и крупные буквы на переднем плане) |
| 245–300 | Видео удаляется и гаснет. **Круг остаётся**: раскрывается в глубину, часть колец надписей поднимается и «висит» над сертификатом. Звук конца видео не обрывается: дальше играет его растянутый хвост (бесшовная петля) |
| **262–298** | Сертификат поднимается из глубины сквозь круг и встаёт перед зрителем |
| **304–356** | Гравировка печати: светящийся фронт идёт сверху вниз по воску, вниз сыплются искры, лист дрожит и медленно наклоняется, звучит синтезированный скрежет. Потом всё возвращается на место |
| 362 | Появляются кнопки. Сцена продолжает жить: пыль, надписи, вращение, реакция на мышь |

### Мышь и глубина

Камера всегда смотрит строго сверху, а мышь (на телефоне касание) сдвигает её вбок.
Одна плоскость «приклеена» к экрану: во время ритуала это верх круга, в финале сертификат.
Всё, что ниже неё (слои круга, видео алтаря как самое дно), смещается **в одну сторону**,
и чем глубже слой, тем сильнее. Получается взгляд в колодец или туннель. Во время ритуала
амплитуда ограничена так, чтобы видео не показывало свои края. Плоскость алтаря при этом
остаётся точно совмещённой с видео.

В финале слои круга разнесены далеко друг от друга по глубине (`FINAL_DEPTH`), но каждый
увеличен ровно настолько, насколько его уменьшает перспектива. Поэтому в покое круг выглядит
как один цельный рисунок, а при движении мыши слои расходятся и видна глубина.

### Магический круг: генерация, а не выбор из вариантов

`src/features/ritual/art/generator.ts` выращивает круг из сида (имя + причина + наказание;
одинаковый текст даёт одинаковый круг):
- **Архитектура глубины:** конус к зрителю, чаша или разброс.
- **Главная фигура:** звезда {n/k}, простой многоугольник, треугольник, составные многоугольники,
  выпуклый «почти круглый» многоугольник, вогнутый, вложенные фигуры или фигура, по граням
  которой бегут буквы. На вершинах точки, кольца, медальоны или спицы.
- **Спутники:** от 2 до 8 кругов на орбите, часто выходят за рамку. Внутри каждого свой
  маленький круг: кольцо букв, пунктир, звезда, сигил или буква. Каждый спутник, медальон и
  медальон на вершине фигуры — отдельный слой: часть из них быстро крутится вокруг своей оси,
  часть почти стоит, а вся группа медленно идёт по орбите.
- **Рамка** разделена на три слоя разной глубины: кольца, пояс надписей и то, что выходит за неё.
- **Рамка:** крупные буквы с разделителями или сплошная надпись. За рамкой лезвия, группы рисок,
  дуги с узлами.
- **Ленты:** орнамент собирается из примитивов с непрерывными случайными параметрами
  (шевроны, дуги, точки, кресты, ромбы, петли, полумесяцы, треугольники, крюки, сигилы, буквы,
  шипы, глаза), плюс волны, косы и зигзаги.
- **Медальоны** на основных направлениях, **механизм** (шестерня, решётка, хорды, цветок),
  **ядро** (сигил, спираль, буква, глаз, светящееся кольцо), призрачная большая геометрия сзади.
- **Сигилы** (`art/sigils.ts`): процедурные кистевые знаки в духе рукописных оккультных меток
  (ось, перекрёстные штрихи, стрелы, полумесяцы, крылья, крюки, завихрения, брызги).
- **Цвет** (`art/palette.ts`): у каждого проклятия **один оттенок**. Структура, надписи и
  акценты отличаются только яркостью и насыщенностью. Оттенки выпадают с весами: красные,
  оранжевые и золотые чаще (около 42%), зелёные, бирюзовые, синие, фиолетовые и розовые реже,
  почти белый «серебряный» очень редко (около 3%).

Сколько разных кругов: структурных комбинаций порядка 10^19 (плюс непрерывные параметры:
радиусы, размеры, углы). На практике предел задаёт 32-битный сид: около 4,3 млрд разных кругов,
каждый новый текст проклятия получает свой. В круге от 9 до 25 слоёв.

Слой рисуется в три канала (R = структура, G = надписи, B = акценты), шейдер окрашивает их в
палитру проклятия. Текстуры рисуются понемногу в каждом кадре, пока падает бумажка,
поэтому страница не подвисает.

Галерея для проверки: `npm run dev` → http://localhost:5173/dev/circles.html?n=24

### Наши буквы

`symbols.svg` содержит 32 буквы. Они читаются по порядку как русский алфавит без «ё»
(а б в … ю я), см. `src/utils/glyphs/translit.ts`. Латиница и армянский сначала
транслитерируются, поэтому любое имя пишется «адским письмом». Эти буквы используются в кольцевых
надписях круга, на бумажке (прожигаются сквозь неё), в подписи и в летающих надписях.

### Сертификат

`src/features/certificate/renderCertificate.ts` рисует его на canvas слоями:
- основа (фон `Sertificate.png`, вырезанный с прозрачным краем, текст, бледный центральный круг);
- печать с оттиском `Pechat.png`, **выдавленным в воске** (тень, блик, глубина);
- маска **увеличенного фрагмента круга**, который заходит на лист сбоку, каждый раз в случайном
  месте. В 3D он окрашен в цвет магии и мягко переливается в зависимости от времени и положения
  мыши, но остаётся фоном бумаги.

С WebGL сертификат — настоящий лист в 3D-сцене (`CERT_FRAG` в `engine/shaders.ts`):
прилетает, гравируется, дрожит, наклоняется за мышью. Скачивается готовый PNG (`final`):
печать уже вырезана, фрагмент круга впитан в бумагу.

### Звук

- звук самих видео (переключатель в правом верхнем углу);
- `public/media/tail.*` — растянутый в 4 раза финальный шум `pribliji` с реверберацией,
  бесшовная петля. Включается, когда видео заканчивается;
- гравировка печати синтезируется в браузере (`src/features/ritual/audio.ts`).

### Память (архив проклятий)

Каждое созданное проклятие сохраняется в **IndexedDB браузера** (`src/features/archive/archiveDb.ts`):
текст, язык, дата и маленькая превьюшка. Полный сертификат перерисовывается из этих данных,
потому что он детерминирован. Кнопка «Архив» открывает список: можно открыть, скачать, повторить
ритуал и удалить. На сервер ничего не уходит. Если IndexedDB недоступен, используется localStorage
(без превью).

### Языки

EN (по умолчанию), RU, HY. Все тексты лежат в одном файле: `src/features/i18n/strings.ts`.
Выбор языка запоминается. Шрифты подключены локально (@fontsource): Cinzel, Cormorant Garamond /
SC, Noto Serif Armenian, Caveat (рукописный на бумажке).

## Структура

```
infernal pact/            исходные ассеты от художников (не редактируются кодом)
scripts/prepare_assets.py конвертер: видео → web MP4/WebM, вырезка сертификата, маска печати
public/media/             готовые видео + постер
src/
  app/App.tsx             сценарий страницы: форма → ритуал → сертификат → архив
  components/             верхняя панель, иконки
  features/
    form/                 форма с валидацией
    ritual/
      timeline.ts         ВСЕ тайминги и кривая наезда камеры
      VideoDeck.ts        два видео, загрузка, точный номер кадра
      audio.ts            хвост звука и синтез гравировки
      params.ts           параметры ритуала из сида
      art/                генератор круга, сигилы, палитра, бумажка
      engine/             WebGL: камера, шейдеры, частицы, буквы, bloom, главный движок
      FallbackStage.ts    упрощённый режим без WebGL
    certificate/          рендер сертификата и анимация появления
    archive/              архив проклятий (IndexedDB) и его окна
    i18n/                 переводы
  utils/                  сид, буквы, шрифты, скачивание
dev/                      dev-страницы: галерея кругов, превью сертификатов
```

## Как заменить ассеты

1. Положите новые файлы в `infernal pact/` с теми же именами.
2. `pip install pillow numpy scipy imageio-ffmpeg && python scripts/prepare_assets.py`
   (можно по шагам: `python scripts/prepare_assets.py certificate seal`).
3. Если изменилась **геометрия** ассета, поправьте замеры:
   - видео: кривую наезда и центр алтаря в `timeline.ts` (`ZOOM_KEYS`, `ALTAR_CENTER_*`, `CONSTRUCT_RADIUS`);
   - бумажка: строки и поля в `art/paperArt.ts` (`RULES`, `MARGIN_X`);
   - сертификат: центр печати и зона текста в `renderCertificate.ts` (`SEAL`, `CONTENT`).

## Производительность и совместимость

- На телефонах ниже плотность пикселей и меньше частиц (`RitualEngine` → `quality`).
- Видео отдаются в H.264 MP4, а там, где H.264 нет, в VP9 WebM.
- Без WebGL работает упрощённый режим: видео + CSS-падение бумажки + тот же сертификат.
- Звук берётся из самих видео и переключается кнопкой; выбор запоминается.
