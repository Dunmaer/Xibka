# Infernal Certificate

(раньше «Проклинатель Online · The Curser Online»)

Страница-игра, где проклинают. Посетитель пишет имя, причину и наказание. Бумажка падает на алтарь,
алтарь затягивает её в вихрь, над ним раскрывается многослойный магический круг, и в конце из
центра рождается сертификат проклятия с восковой печатью. Всё работает в браузере, на сервер ничего
не отправляется. Проклятия сохраняются в архиве на компьютере пользователя.

Стек: **Vite + React + TypeScript + Three.js + GSAP**, без бэкенда.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # production-сборка в dist/
npm run preview      # посмотреть собранную версию
```

Нужен Node.js 22 (или 20.19+).

## Публикация

Сайт полностью статический: собирается в папку `dist/`, все пути относительные (`base: './'`),
поэтому он работает и из подпапки, и внутри iframe.

### GitHub Pages (https://infernalcertificate.org)

`.github/workflows/pages.yml` собирает и публикует сайт при каждом пуше в ветку
`claude/elegant-maxwell-kh7983` (и в `main`), а также по кнопке **Run workflow** во вкладке Actions.
Один раз в настройках репозитория:
1. **Settings → General → Danger Zone → Change visibility → Public** (на бесплатном тарифе Pages
   работает только для публичных репозиториев);
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**;
3. если деплой из этой ветки отклонён: **Settings → Environments → github-pages → Deployment
   branches** → добавить `claude/elegant-maxwell-kh7983`.

Свой домен `infernalcertificate.org` подключён в **Settings → Pages → Custom domain**
(DNS смотрит на GitHub Pages). Адрес сайта для canonical, превью в соцсетях, `robots.txt` и `sitemap.xml` задаётся в
`vite.config.ts` (`SITE_URL`). В `index.html` есть описание для поисковиков, которое видно и без
JavaScript, и разметка schema.org (VideoGame). `robots.txt` разрешает всех, в том числе
OAI-SearchBot (поиск ChatGPT).

## Как устроен ритуал

Всё синхронизировано с **номером кадра видео `pribliji.mp4`** (24 fps, 271 кадр).
Номер кадра берётся из `requestVideoFrameCallback`, поэтому эффекты попадают точно в кадр.
Все тайминги собраны в одном файле: `src/features/ritual/timeline.ts`.

| Кадры `pribliji` | Что происходит |
|---|---|
| до старта | Крутится `stable.mp4`. После «Начать ритуал» бумажка с текстом появляется перед зрителем и падает листом на центр алтаря |
| 0–175 | Включается `pribliji.mp4` (стык подобран без шва). Бумажка лежит на камне: греется, по краям темнеет, сквозь неё проступают «адские» буквы в цвете проклятия |
| **175** | Открывается **туннель**: части круга, кольца надписей, сигилы и спутники летят из глубины вихря |
| 175–245 | Камера ныряет в вихрь (масштаб замерен по видео). Части круга по одной прилетают на свои места и **собираются в круг** (у каждого своя вспышка фиксации). Другие элементы пролетают мимо камеры и уходят за кадр. Бумажка проваливается в туннель и сгорает |
| **245** | Круг собран: удар, искры, огонь, появляются летящие надписи (цепочки букв и крупные буквы на переднем плане) |
| 245–300 | Видео удаляется и гаснет. **Круг остаётся**: раскрывается в глубину, часть колец надписей поднимается и «висит» над сертификатом. Звук конца видео не обрывается: дальше играет его растянутый хвост (бесшовная петля) |
| **262–298** | Сертификат поднимается из глубины сквозь круг и встаёт перед зрителем |
| **304–356** | Гравировка печати: светящийся фронт идёт сверху вниз по воску, вниз сыплются искры, лист дрожит и медленно наклоняется, звучит синтезированный скрежет. Потом всё возвращается на место |
| 362 | Появляются кнопки. Сцена продолжает жить: пыль, надписи, вращение, реакция на мышь |

### Мышь и глубина

Камера всегда смотрит строго сверху, а мышь сдвигает её вбок. На телефоне мыши нет, поэтому
камера всё время медленно плывёт сама, а **наклон телефона** её ведёт (`src/features/ritual/motion.ts`;
считается только изменение наклона, так что держать телефон можно как угодно). Касание пальцем
тоже работает. iPhone один раз спрашивает разрешение на датчики движения при нажатии «Начать ритуал»
или при первом касании.
Одна плоскость «приклеена» к экрану: во время ритуала это верх круга, в финале сертификат.
Всё, что ниже неё (слои круга, видео алтаря как самое дно), смещается **в одну сторону**,
и чем глубже слой, тем сильнее. Получается взгляд в колодец или туннель. Во время ритуала
амплитуда ограничена так, чтобы видео не показывало свои края. Плоскость алтаря при этом
остаётся точно совмещённой с видео.

В финале слои круга разнесены далеко друг от друга по глубине (`FINAL_DEPTH`), но каждый
увеличен ровно настолько, насколько его уменьшает перспектива. Поэтому в покое круг выглядит
как один цельный рисунок, а при движении мыши слои расходятся и видна глубина.

### Магический круг: генерация, а не выбор из вариантов

`src/features/ritual/art/generator.ts` выращивает круг из сида (имя + причина + наказание;
одинаковый текст даёт одинаковый круг):
- **Архитектура глубины:** конус к зрителю, чаша или разброс.
- **Главная фигура:** звезда {n/k}, простой многоугольник, треугольник, составные многоугольники,
  выпуклый «почти круглый» многоугольник, вогнутый, вложенные фигуры, фигура, по граням
  которой бегут буквы, **квадратная печать** (слова идут по четырём сторонам, в углах ячейки,
  внутри ромб, круг, «окно» или диагонали), **куб Метатрона** (13 кругов и линии между ними),
  **цветок жизни**, **куб** (ближний угол сплошными линиями, дальний пунктиром). На вершинах
  точки, кольца, узлы с отростками, спицы или медальоны (на треугольнике и квадрате крупные).
- **Внецентренные круги** (примерно в половине кругов): большие круги на вершинах фигуры, круги
  не по центру с надписью вдоль них (ломают симметрию), розетка кругов через центр или орбиты-эллипсы.
- **Ось** (около 30%): линия через весь круг, выходит за рамку; на концах узел, полумесяц,
  стрела, трезубец, кольцо, ромб или треугольник, по пути поперечины с узлами. Симметрия
  только зеркальная, концы разные.
- **Цепочка бусин** (около 35%): уменьшающиеся кружки с буквами или сигилами за рамкой, с одной стороны.
- **Спутники:** от 2 до 8 кругов на орбите, часто выходят за рамку. Три режима: ровно по кругу;
  «созвездие» — несколько крупных печатей, связанных с центром двойными брусьями с надписями и
  между собой; «разброс» — разные размеры и неровные промежутки. Связи крутятся вместе со
  спутниками. Внутри каждого спутника свой маленький круг: кольцо букв, пунктир, звезда, тёмная
  лента с вырезанными буквами, солнце или лотос, в центре сигил, звезда, буква, полумесяц,
  вырезанный сигил или глаз. Каждый спутник, медальон и медальон на вершине фигуры — отдельный
  слой: часть из них быстро крутится вокруг своей оси, часть почти стоит, а вся группа медленно
  идёт по орбите.
- **Рамка** разделена на три слоя разной глубины: кольца, пояс надписей и то, что выходит за неё.
- **Рамка:** сплошная надпись, крупные буквы с разделителями, кольцо кистевых сигилов (часть в
  кружках) или тёмная лента с вырезанными буквами. За рамкой лезвия, группы рисок, дуги с узлами.
- **Ленты:** кольцо букв, тёмная лента с вырезанными буквами, кольцо сигилов, нитка бусин с
  буквами или орнамент из примитивов с непрерывными случайными параметрами (шевроны, дуги, точки,
  кресты, ромбы, петли, полумесяцы, треугольники, крюки, сигилы, буквы, шипы, глаза), плюс волны,
  косы и зигзаги. Внутри квадратной печати ленты помещаются в её внутренний квадрат.
- **Медальоны** на основных направлениях, **механизм** (шестерня, решётка, хорды, цветок),
  **ядро** (сигил, спираль, буква, глаз, полумесяц со звездой, солнце, лотос, глаз в треугольнике
  или один большой кистевой сигил без печати), призрачная большая геометрия сзади.
- **Сигилы** (`art/sigils.ts`): процедурные кистевые знаки в духе рукописных оккультных меток
  (ось, перекрёстные штрихи, стрелы, полумесяцы, крылья, крюки, завихрения, брызги).
- **Цвет** (`art/palette.ts`): у каждого проклятия **один оттенок**. Структура, надписи и
  акценты отличаются только яркостью и насыщенностью. Оттенки выпадают с весами: красные,
  оранжевые и золотые чаще (около 42%), зелёные, бирюзовые, синие, фиолетовые и розовые реже,
  почти белый «серебряный» очень редко (около 3%).

Сколько разных кругов: структурных комбинаций, по грубой оценке, порядка 10^25 (плюс непрерывные
параметры: радиусы, размеры, углы). На практике предел задаёт 32-битный сид: около 4,3 млрд
разных кругов, каждый новый текст проклятия получает свой. В круге от 7 до 38 слоёв, обычно около 19.

Слой рисуется в три канала (R = структура, G = надписи, B = акценты), шейдер окрашивает их в
палитру проклятия. Текстуры рисуются понемногу в каждом кадре, пока падает бумажка,
поэтому страница не подвисает.

Галерея для проверки: `npm run dev` → http://localhost:5173/dev/circles.html?n=24

### Наши буквы

`symbols.svg` содержит 32 буквы. Они читаются по порядку как русский алфавит без «ё»
(а б в … ю я), см. `src/utils/glyphs/translit.ts`. Латиница и армянский сначала
транслитерируются, поэтому любое имя пишется «адским письмом». Эти буквы используются в кольцевых
надписях круга, на бумажке (прожигаются сквозь неё), в подписи и в летающих надписях.

### Сертификат

`src/features/certificate/renderCertificate.ts` рисует его на canvas слоями:
- основа (фон `Sertificate.png`, вырезанный с прозрачным краем, текст, бледный центральный круг);
- печать с оттиском `Pechat.png`, **выдавленным в воске** (тень, блик, глубина);
- маска **увеличенного фрагмента круга**, который заходит на лист сбоку, каждый раз в случайном
  месте. В 3D он окрашен в цвет магии и мягко переливается в зависимости от времени и положения
  мыши, но остаётся фоном бумаги.

С WebGL сертификат — настоящий лист в 3D-сцене (`CERT_FRAG` в `engine/shaders.ts`):
прилетает, гравируется, дрожит, наклоняется за мышью. Скачивается готовый PNG (`final`):
печать уже вырезана, фрагмент круга впитан в бумагу.

### Звук

Два набора, выбираются в `src/config.ts` (`SOUND_SET_DEFAULT`). Любую страницу можно открыть
с `?sound=old` или `?sound=new`, чтобы сравнить.

**Новый набор** (по умолчанию) собран из звуков папки `Sounds/` (авторы и ссылки в
`Sounds/CREDITS.md`). Видео при этом молчат, весь звук играет `src/features/ritual/soundscape.ts`:
- **фон, который не прерывается:** ветер пещеры и треск огня. Звучит с первого касания страницы:
  браузеры не дают играть звук раньше (страница пробует на каждом касании, пока браузер не
  разрешит; на iPhone звук играет и при включённом беззвучном режиме). В случайные моменты гремит гром (вырезаны самые резкие
  удары, сверху добавлен синтезированный треск и низкий удар) и стонет пещера, каждый раз с
  другой высотой и с другой стороны;
- **ритуал по кадрам:** жар и огонь нарастают; на кадре 166 гром; с 175 включается ровный гул
  магического круга (он не выключается до конца); нырок сопровождает свист, а обратный свист
  нарастает точно в удар 245. Когда загорается бумажка, огонь вспыхивает. На 245 гром,
  извержение огня и низкий удар, а за долю секунды до него фон проседает, чтобы удар был сильнее.
  Потом всё оседает в финальный фон: пещера, огонь, далёкий гром, а когда главная анимация
  закончилась (кадр 362), гул круга становится в 5 раз тише;
- **музыка** «Grinding Inferno» (`Sounds/Grinding Inferno.mp3` → `public/media/music.*`) играет
  всё время, пока открыт сайт, отдельно от ритуала, на 25% громкости (`MUSIC_VOLUME` в
  `audio.ts`). Она идёт потоком из двух плееров по очереди: конец трека перетекает в начало
  (кроссфейд 6 с), шва нет;
- **мелкие звуки по движению:** искра, когда часть круга встаёт на место (выше для маленьких
  частей, слева или справа по её положению), взмах, когда деталь туннеля пролетает мимо камеры,
  взмах и искра, когда поднимается сертификат;
- гравировка печати синтезированная; после неё звучат 2–3 тёмные ноты «колокола», каждый раз
  разные, каждая следующая тише.

Швов нет: петли склеиваются после загрузки равномощным кроссфейдом их собственных концов, а все
переходы между состояниями плавные и могут накладываться. Общий звук проходит через компрессор
и ограничитель, поэтому гром поверх взрыва не хрипит. Когда вкладка скрыта, звук на паузе.

Послушать весь ритуал без кликов: `npm run dev` → http://localhost:5173/dev/sound.html
(страница рендерит саундтрек тем же кодом и даёт скачать WAV; `?mute=thunder1,beds` убирает части).
Чтобы заменить звуки: положите файлы в `Sounds/` и поправьте нарезку в `sounds()` в
`scripts/prepare_assets.py`, громкости в `LEVELS` и в `frame()` в `soundscape.ts`.

**Старый набор:** звук самих видео плюс `public/media/tail.*` — растянутый в 4 раза финальный шум
`pribliji` с реверберацией, бесшовная петля после конца видео. Гравировка та же.

Звук включается и выключается кнопкой в правом верхнем углу, выбор запоминается.

### Память (архив проклятий)

Каждое созданное проклятие сохраняется в **IndexedDB браузера** (`src/features/archive/archiveDb.ts`):
текст, язык, дата и маленькая превьюшка. Полный сертификат перерисовывается из этих данных,
потому что он детерминирован. Кнопка «Архив» открывает список: можно открыть, скачать, повторить
ритуал и удалить. На сервер ничего не уходит. Если IndexedDB недоступен, используется localStorage
(без превью).

### Кнопка «Поддержать» (донат)

Ссылка задаётся в одном месте, `src/config.ts`:

```ts
const DONATE_LINK = 'https://ko-fi.com/yourname';
```

Пока там пусто, кнопки нет. Когда ссылка есть, появляются кнопка с сердцем в верхней панели и
строка «Понравился ритуал? Покорми алтарь» под кнопками сертификата. Ссылку можно задать и без
правки кода: переменная окружения `VITE_DONATE_URL` в настройках хостинга (после этого нужна
пересборка). Сам сайт деньги не принимает: кнопка просто открывает страницу выбранного сервиса
(Ko-fi, Buy Me a Coffee, Boosty, Patreon, PayPal.me, DonationAlerts и т. п.).

### Языки

EN (по умолчанию), RU, HY. Все тексты лежат в одном файле: `src/features/i18n/strings.ts`.
Выбор языка запоминается. Шрифты подключены локально (@fontsource): Cinzel, Cormorant Garamond /
SC, Noto Serif Armenian, Caveat (рукописный на бумажке).

```
      VideoDeck.ts        два видео, загрузка, точный номер кадра
      audio.ts            хвост звука и синтез гравировки
      params.ts           параметры ритуала из сида
      art/                генератор круга, сигилы, палитра, бумажка
      engine/             WebGL: камера, шейдеры, частицы, буквы, bloom, главный движок
      FallbackStage.ts    упрощённый режим без WebGL

    archive/              архив проклятий (IndexedDB) и его окна

```

## Как заменить ассеты

1. Положите новые файлы в `infernal pact/` с теми же именами.
2. `pip install pillow numpy scipy imageio-ffmpeg && python scripts/prepare_assets.py`
   (можно по шагам: `python scripts/prepare_assets.py certificate seal`).
3. Если изменилась **геометрия** ассета, поправьте замеры:
   - видео: кривую наезда и центр алтаря в `timeline.ts` (`ZOOM_KEYS`, `ALTAR_CENTER_*`, `CONSTRUCT_RADIUS`);
   - бумажка: строки и поля в `art/paperArt.ts` (`RULES`, `MARGIN_X`);
   - сертификат: центр печати и зона текста в `renderCertificate.ts` (`SEAL`, `CONTENT`).

## Отладка

| URL | Что делает |
|---|---|
| `?debug` | показывает номер кадра F |
| `?autoplay` | сразу запускает ритуал с тестовым проклятием (на текущем языке) |
| `?frame=230` | замирает на кадре 230 (удобно подгонять эффекты) |
| `?frame=190&layers=figure,core` | показывает только выбранные слои круга (проверка синхронизации с видео) |
| `?autoplay&name=Viktor85` | тестовое проклятие с другим именем, то есть другой круг |
| `/dev/circles.html?n=24` | галерея сгенерированных кругов |
| `/dev/certificate.html` (`?long=1`) | сертификаты на трёх языках (длинные тексты) |
| `/dev/sound.html` | весь саундтрек ритуала, отрендеренный офлайн (плеер + WAV) |
| `?sound=old` / `?sound=new` | старый или новый набор звуков |

## Производительность и совместимость

- На телефонах ниже плотность пикселей и меньше частиц (`RitualEngine` → `quality`).
- Видео отдаются в H.264 MP4, а там, где H.264 нет, в VP9 WebM.
- Без WebGL работает упрощённый режим: видео + CSS-падение бумажки + тот же сертификат.
