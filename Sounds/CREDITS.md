# Sounds

All sounds come from [freesound.org](https://freesound.org). The number at the start of each
file name is the sound's id: its page is `https://freesound.org/s/<id>/`, where the licence is
shown. Sounds under CC BY need the author credited (for example on an "About" page or in this
list); CC0 needs nothing.
